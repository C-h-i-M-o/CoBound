# 用户画像分析

## 画像一：普通学生
- 姓名：李同学
- 目标：按时完成自己负责的任务，不遗漏重要通知。
- 行为特征：主要使用手机和浏览器，习惯看简洁任务清单。
- 痛点：群消息分散，容易忘记截止时间。
- 核心需求：个人待办、通知确认、Deadline提醒。

## 画像二：学生负责人
- 姓名：陈同学
- 目标：协调团队成员，保证项目按阶段推进。
- 行为特征：经常查看团队进度和成员响应状态。
- 痛点：催进度成本高，任务责任边界不清。
- 核心需求：任务分配、进度看板、风险预警。

## 画像三：课程教师
- 姓名：王老师
- 目标：掌握课程项目过程，辅助评价团队和成员贡献。
- 行为特征：关注整体进展、延期团队和阶段提交。
- 痛点：过程数据缺失，最终评分依据不足。
- 核心需求：课程项目总览、团队详情、贡献度参考。

## 画像四：系统管理员
- 姓名：赵管理员
- 目标：维护平台基础数据和运行配置。
- 行为特征：低频使用，重视稳定和可控。
- 痛点：用户、课程、通知模板分散维护。
- 核心需求：用户管理、课程管理、系统配置。
