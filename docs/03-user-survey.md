# 用户调研问卷

## 调研说明
本问卷用于了解高校学生在课程项目、小组作业和竞赛项目中的协作痛点。以下数据为基于目标场景整理的合理模拟材料，用于支撑原型迭代和需求规格说明。

## 样本概况
- 回收问卷：86份
- 有效问卷：82份
- 受访对象：本科生、研究生、课程助教
- 专业分布：计算机、设计、管理、电子信息、外语等

## 核心问题与结果
| 问题 | 主要结果 |
| --- | --- |
| 是否遇到过组队困难 | 73%表示经常或偶尔遇到 |
| 最常用协作工具 | 微信/QQ群78%，在线文档62%，任务工具18% |
| 最常见协作问题 | 任务不明确69%，进度不透明64%，临近DDL赶工58% |
| 是否需要消息确认 | 81%认为重要或非常重要 |
| 是否希望教师看到过程数据 | 66%支持，24%视课程而定 |
| 是否接受贡献度参考分 | 71%接受，但希望教师可调整 |

## 开放反馈摘要
- “很多任务只在群里说一遍，后面就找不到了。”
- “队长需要不停催进度，压力很大。”
- “有的人不做事，但最后很难拿出证据说明。”
- “老师只看最终成果，不知道过程里谁做了什么。”

## 需求启示
- 系统需要将任务、截止时间和负责人结构化记录。
- 通知需要有确认状态，避免重要消息被忽略。
- 进度跟踪应轻量，不应增加过多填报负担。
- 贡献度应可解释，并保留教师人工调整空间。
