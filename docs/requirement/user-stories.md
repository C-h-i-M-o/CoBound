# 协界（CoBound）用户故事

> **版本**: 1.0 | **日期**: 2026-06-11 | **课程**: 软件需求分析

---

## 1. 用户故事总览

本文档以用户故事（User Story）格式描述 CoBound 系统的功能需求。每个故事遵循标准模板：

> **作为** \<角色\>，**我希望** \<功能\>，**以便** \<价值\>

按功能模块分组，并按优先级（P0 最高 → P3 最低）排序。

---

## 2. 学生用户故事

### 2.1 账户与入门

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-001 | P0 | 作为学生，我希望通过邀请链接完成注册，以便加入项目协作 | 点击有效邀请链接后可在中文引导下完成五步注册；无效链接给出明确提示 |
| US-002 | P0 | 作为学生，我希望用用户名和密码登录，以便访问我的项目 | 输入正确凭据后进入工作台；错误凭据有中文提示 |
| US-003 | P1 | 作为学生，我希望修改个人密码和头像，以便管理我的账户 | 在个人设置页可修改密码（需旧密码验证）和上传头像 |
| US-004 | P1 | 作为学生，我希望选择亮色/暗色主题和字体，以便获得舒适的阅读体验 | 主题切换即时生效，偏好持久化保存 |
| US-005 | P2 | 作为学生，忘记密码时我希望知道如何重置，以便恢复访问 | 忘记密码页面显示"请联系管理员重置密码"提示 |

### 2.2 任务协作

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-010 | P0 | 作为项目成员，我希望在看板上看到所有任务及其状态，以便了解项目全貌 | 看板按状态分列展示任务卡片，卡片显示标题、负责人、优先级、截止日期 |
| US-011 | P0 | 作为项目成员，我希望拖放任务卡片改变状态，以便快速更新工作进展 | 拖放后任务状态即时更新，通知相关人员 |
| US-012 | P0 | 作为项目成员，我希望创建新任务并指定负责人和截止日期，以便明确分工 | 创建时可填写标题、描述、负责人、优先级、截止日期、标签 |
| US-013 | P1 | 作为任务负责人，我希望收到任务分配通知，以便及时了解新工作 | 被分配任务时在站内收到通知 |
| US-014 | P1 | 作为项目成员，我希望按优先级/状态/负责人筛选任务，以便聚焦当前关注的内容 | 筛选器选择后即时过滤看板/列表内容 |
| US-015 | P1 | 作为项目成员，我希望能按成员或优先级创建看板泳道，以便多维度查看任务分布 | 分组选择后看板自动显示泳道分隔 |
| US-016 | P2 | 作为项目成员，我希望能评论任务并 @提及其他成员，以便就具体问题沟通 | 评论后相关人员收到通知；支持回复形成讨论串 |

### 2.3 进度与规划

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-020 | P0 | 作为项目成员，我希望在路线图上看到所有里程碑的时间安排，以便把握项目节奏 | 甘特图展示里程碑起止时间，可拖放调整 |
| US-021 | P1 | 作为项目成员，我希望看到项目整体进度百分比，以便评估是否按时完成 | 仪表盘上进度条反映任务完成比例 |
| US-022 | P1 | 作为项目成员，我希望用红/黄/绿快速发布状态更新，以便团队了解我的进展 | 选择颜色并输入文字后，状态发布在项目时间线上 |
| US-023 | P2 | 作为项目成员，我希望查看迭代燃尽图，以便判断迭代进度是否健康 | 燃尽图展示计划 vs 实际工作量随时间变化 |

### 2.4 个人效率

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-030 | P1 | 作为项目成员，我希望在"我的工作"页面看到所有待办任务，以便规划每日工作 | 页面展示当前所有分配给我的任务，按截止日期排序 |
| US-031 | P1 | 作为项目成员，我希望能启动计时器记录工时，以便准确汇报投入 | 点击开始计时，完成后工时记录保存到工时表 |
| US-032 | P2 | 作为项目成员，我希望查看个人日历，以便安排任务时间 | 日历上显示任务截止日期和个人事件 |

### 2.5 知识管理

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-040 | P2 | 作为项目成员，我希望能上传和浏览项目文件，以便共享资料 | 文件上传后出现在项目文件列表中，支持下载 |
| US-041 | P3 | 作为项目成员，我希望创建和编辑 Wiki 文档，以便沉淀团队知识 | 可创建多空间、编写和编辑文档 |

## 3. 教师/负责人用户故事

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-050 | P0 | 作为教师，我希望能为每门课程创建独立项目，以便管理不同课程的学生团队 | 创建项目时可设置名称、权限范围、初始成员 |
| US-051 | P0 | 作为教师，我希望能邀请学生加入项目，以便组队完成课程任务 | 创建用户后生成邀请链接，可复制发送给学生 |
| US-052 | P1 | 作为教师，我希望能查看各组成员的贡献情况，以便客观评估个人成绩 | 可查看成员工时记录、任务完成数量、目标进度 |
| US-053 | P1 | 作为教师，我希望创建课程里程碑（如开题、中期检查、终期答辩），以便设定阶段性节点 | 里程碑设置后学生可在路线图上看到截止日期 |
| US-054 | P1 | 作为教师，我希望能查看各小组的目标完成度，以便了解整体进展 | 目标页面展示各目标的进度百分比和关联任务状态 |
| US-055 | P2 | 作为教师，我希望能查看项目的完整过程记录，以便评估团队协作质量 | 可浏览任务变更历史、评论记录、文件上传记录 |

## 5. 新手引导用户故事

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-070 | P1 | 作为新用户，我希望能通过分步引导了解系统功能，以便快速上手 | 首次进入关键页面时弹出中文引导弹窗 |
