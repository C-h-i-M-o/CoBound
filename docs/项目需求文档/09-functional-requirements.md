# 功能需求说明

## 学生端
| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| FR-S-01 | 课程项目浏览 | 学生可查看可参与的课程项目 | 高 |
| FR-S-02 | 组队意向 | 学生可发布兴趣、技能和可投入时间 | 高 |
| FR-S-03 | 团队申请 | 学生可申请加入团队并查看处理状态 | 高 |
| FR-S-04 | 项目空间 | 团队成员可查看项目概况、成员、任务和提醒 | 高 |
| FR-S-05 | 任务管理 | 负责人可创建、分配、编辑任务 | 高 |
| FR-S-06 | 进度上报 | 成员可更新任务状态和说明 | 高 |
| FR-S-07 | 通知确认 | 成员需确认重要任务、Deadline和风险通知 | 高 |
| FR-S-08 | 风险查看 | 成员可查看与自己相关的风险原因 | 中 |

## 教师端
| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| FR-T-01 | 课程项目管理 | 教师可创建和维护课程项目 | 高 |
| FR-T-02 | 团队总览 | 教师可查看团队进度、任务完成率和风险 | 高 |
| FR-T-03 | 风险预警 | 教师可查看逾期、未确认和低进度团队 | 高 |
| FR-T-04 | 贡献度参考 | 系统生成成员过程贡献参考 | 中 |
| FR-T-05 | 贡献度调整 | 教师可人工调整贡献度并填写理由 | 中 |

## 管理员端
| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| FR-A-01 | 用户管理 | 管理学生、教师和管理员账号 | 高 |
| FR-A-02 | 课程数据管理 | 维护课程、班级、学期等基础数据 | 高 |
| FR-A-03 | 通知模板管理 | 维护系统通知文案模板 | 中 |
| FR-A-04 | 系统配置 | 维护基础开关和风险阈值 | 中 |
